# Archived implementations and materials

- `previous-root/`: original root files and prototypes, including the former README and audio samples.
- `versioned-implementations/`: `Master`, `Hearing`, `final`, and `old version` trees.

See [repository map](../REPOSITORY_MAP.md). Local uncommitted changes are not on GitHub; back them up separately.
